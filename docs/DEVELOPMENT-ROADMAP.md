
# Development Roadmap

Project: Test Case & Bug Tracking Web App

Status: Locked

Target Budget: Rp0

Estimated Duration: 18–20 Days

## Day 1 — Project Setup
- [x] Create React + Vite project.
- [x] Configure ESLint.
- [x] Install and configure Tailwind CSS.
- [x] Install and configure React Router.
- [x] Initialize Git repository.
- [x] Connect project to GitHub.
- [ ] Prepare project documentation.
- [ ] Connect project to Supabase.

## Day 2 — Database & Authentication
- Create database tables.
- Configure database relationships.
- Configure Supabase Authentication.
- Configure Guest and Admin access.

## Day 3 — Layout & Dashboard
- Create application layout.
- Create navigation and sidebar.
- Create Guest and Admin layouts.
- Build initial dashboards.

## Day 4 — Module Management
- Create Module list.
- Implement Add, Edit, and Delete Module.
- Implement Module publication settings.

## Day 5–6 — Test Case Management
- Create Test Case list and detail.
- Implement Test Case CRUD.
- Implement automatic Test Case ID.
- Implement priority settings.
- Implement public Test Case visibility.

## Day 7 — Test Execution
- Create Release.
- Define Test Case scope for each Release.
- Record execution results.
- Preserve execution history.

## Day 8–9 — Bug Tracking
- Implement Bug Report CRUD.
- Configure severity and status.
- Link Bugs with Test Cases.
- Create Kanban Board.
- Implement evidence upload.

## Day 10–11 — Dashboard & Excel Export
- Calculate Test Case statistics.
- Calculate Bug statistics.
- Create dashboard charts.
- Implement Excel export.

## Day 12–14 — Release Management & Report
- Implement Release Management.
- Calculate testing metrics automatically.
- Provide manual conclusion and recommendation fields.
- Generate Release Documents in DOCX and PDF.

## Day 15–17 — Testing & Improvements
- Test application features.
- Test Guest and Admin permissions.
- Verify public data visibility.
- Fix bugs.
- Improve UI consistency.

## Day 18–20 — Deployment & Finalization
- Deploy application to Vercel.
- Configure production Supabase.
- Prepare public demo data.
- Verify public access.
- Perform final portfolio review.
